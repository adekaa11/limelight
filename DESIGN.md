# DESIGN.md — Проявка

## Характер
Личный дневник, который превращает день в воспоминание. Тихо, тепло, «бумажно»: интерфейс как фотоальбом и тёмная комната проявки, он не спорит с фото пользователя. Избегаем: ярких градиентов, неона, стекла с блюром, стоковых людей, иконок ради иконок.

**Фирменный приём:** вертикальная страница 9:16 с фото в паспарту, датой и названием сверху, рукописной подписью внизу и полоской палитры дня (5 цветов) под ней. Проходит через архив, экран загрузки, плеер, презентацию и видео.

## Цвета
| Токен | hex | Где |
|---|---|---|
| `paper` | `#F4EFE6` | фон сайта и светлых слайдов |
| `paper2` | `#EBE4D6` | вторичный фон, карточки, полосы |
| `ink` | `#2B2622` | текст, основная кнопка, тёмные слайды («тёмная комната») |
| `muted` | `#7A7066` | подписи, второстепенный текст |
| `line` | `#D9D0C1` | границы, разделители |
| `accent` | `#A0522D` | сиена: акцент, ссылки, ключевые цифры |
| `print` | `#FAF6EE` | «фотобумага»: страница-воспоминание, книга |

Палитры дней (переменные) приходят от `style_engine` и используются только внутри страниц-воспоминаний и полосок палитры, никогда в интерфейсе.

## Шрифты
- **Cormorant Garamond** (600): название продукта, заголовки, даты и названия дней.
- **Inter** (400/500): интерфейс и текст.
- **Caveat**: только рукописные подписи и заметки на полях.

Шкала сайта: 12 / 14 / 16 / 24 / 36. Слайды 16:9: 54 обложка, 32 заголовок, 16 текст, 11 подписи. Выделение жирностью или цветом, не новым размером.

## Форма и отступы
- Скругления почти нет: 2–3px у карточек и страниц, кнопки-«пилюли» `rounded-full`.
- Границы 1px `line`. Тень только у страниц-воспоминаний: `0 20px 50px -20px rgba(60,40,20,.45)`.
- Фон сайта: еле заметное зерно (точки 1px, 6% непрозрачности).
- Поля страницы-воспоминания 6%, паспарту: белая рамка 3% вокруг фото.

## Компоненты
- **Страница-воспоминание (Poster):** 9:16, фон `palette[0]`, дата (Cormorant), название, фото в паспарту, подпись Caveat, номер страницы.
- **Полоска палитры (PaletteStrip):** 5 равных прямоугольников без зазоров.
- **Кнопки:** основная — `ink` с текстом `paper`; вторичная — контур `ink/20`.
- **Карточка:** `#FAF7F1`, граница `line`, без теней.
- **Метка:** 11px, капс, разрядка 0.14em, `muted`; только над группами полей, не над каждым блоком.
- **Рецепт дня:** вход → правила → результат, правила строками «условие → следствие».
- **Первый экран (Intro):** заголовок, 3 шага с цифрами-акцентом (сиена), кнопка «Записать день», справа пример страницы. Скрывается «больше не показывать».
- **Тёмная комната (экран «Проявляем день»):** весь экран `ink`, текст `paper` (вторичный — `paper/60`), страница поднимается из темноты по прогрессу (яркость 12% → 100%), фото — из ч/б и размытия в цвет. Кнопки инвертированы: основная `paper` с текстом `ink`.
- **Год в цветах:** пустой день — только бледная цифра без плашки; записанный — клетка из 5 полос палитры, при наведении всплывает страница; под календарём строка записанных дней с полосками палитр.
- **Как это работает (/rules):** разделы с номером-акцентом: схема страницы с номерами постоянных элементов, таблица переменных, 5 техник с мини-страницами, таблица баллов, правила «условие → следствие».
- **Превью ссылки (og.jpg, 1200×630):** бумага, «Проявка» Cormorant 88, подзаголовок, три страницы лесенкой с полосками палитр. Только страницы без узнаваемых людей.
- **Страница дня:** название в одну строку с соседними днями, плеер по центру во всю высоту экрана, под ним одна строка кнопок «▶ Открыть день · Озвучка · ⇣ Скачать папку · ● Видео», ниже «Рецепт дня» в три колонки.

## Тексты
На «ты», коротко, спокойно. Глаголы в кнопках: «Записать день», «Проявить», «Скачать папку». Ошибки по-человечески и с выходом: «Не получилось проявить день. Попробовать ещё раз».

## Не делать
- Чистые `#FFFFFF`/`#000000` для фонов и текста.
- Цвета палитр дней в интерфейсе.
- Декоративные полосы по краям, подчёркивания под заголовками.
- Больше одного акцентного цвета на экране/слайде (кроме палитр дней).
- Генеративные картинки: всё визуальное строится из фото пользователя.
