# Презентация «Проявка» (для Canva)

**Стиль на все слайды:** фон бумажный `#F5EFE6`, текст `#2B2622`. Заголовки Cormorant Garamond, текст Inter. Повторяющийся приём: справа на каждом слайде вертикальная «страница» 9:16 (скриншот воспоминания) и полоска палитры дня под ней. Формат 16:9.

Слайд = одна мысль, заголовок = вывод. `[__]` = вписать перед сдачей.

---

### 1. Обложка
**Заголовок:** Проявка
**Подзаголовок:** Дневник, который помнит, как ощущался день
**Мелко:** Genesis Hackathon 2026 · ArtTech «Make the Invisible Visible» · Адильжан, Еркайнар, Дан, Алимжан · proyavka-eight.vercel.app
**Визуал:** 3 страницы-воспоминания веером (Моне, Кандинский, плёнка).
**Сказать:** «Мы сделали дневник, который превращает запись о дне в живое воспоминание под музыку этого дня».

### 2. Проблема
**Заголовок:** Фото помнят, как выглядел день, но не как он ощущался
**Текст:** Через год в галерее остаются кадры без песни, которая играла, без запаха какао, без усталости после релиза. Текстовый дневник перечитывать скучно, галерея молчит.
**Визуал:** сетка обычных фото из галереи, серые.
**Сказать:** личный пример кого-то из команды, 1 фраза.

### 3. Решение: 3 шага
**Заголовок:** Три ввода → одно воспоминание
**Карточки:**
1. Пишешь пару абзацев о дне
2. Добавляешь фото и песню (ссылка или файл)
3. Получаешь страницу 9:16, которая играет под эту песню, и папку дня с названием («Осенний парк и какао»)
**Визуал:** скриншоты экрана `/new` → экран «Проявляем день» → готовое воспоминание.

### 4. Что видит пользователь
**Заголовок:** Воспоминание живёт в ритме песни
**Карточки:**
- Фото меняются ровно на биты песни
- Смена части песни = смена сцены
- Запахи и звуки из текста пишутся от руки на полях
- Старые дни выцветают и при открытии «проявляются» 3 секунды
- Озвучка текста голосом под настроение
**Визуал:** GIF/кадры плеера.

### 5. Визуальная система
**Заголовок:** Постоянное держит серию, переменное делает день своим
**Две колонки:**
- Постоянное: 9:16, поля 6%, дата и название (Cormorant), фото в паспарту, подпись от руки, номер страницы
- Переменное: техника, палитра, зерно, ритм кадров, движение, плотность, жирность шрифта, голос
**Визуал:** лента из 5 страниц подряд.

### 6. Пять техник
**Заголовок:** Техника выбирается по настроению дня, а не наугад
**Таблица:** Моне — спокойно и тепло · Кандинский — напряжение, ночь, электроника · Плёнка — ностальгия, старые песни · Коллаж Матисса — радость, много людей · Японский минимализм — тишина, дождь
**Визуал:** по одной странице каждой техники.
**Сказать:** «Выбор по таблице баллов: например, японский получает баллы за тишину, дождь, медленный минор и отсутствие людей».

### 7. Объяснимые правила
**Заголовок:** Каждое решение можно объяснить
**Пример «Рецепта дня» (реальный вывод системы):**
- 128 BPM → смена кадра на каждый 4-й бит
- ночь → тёмный сине-серый фон
- минор → насыщенность −25%
- песне 38 лет («Группа крови», 1988) → больше зерна
- палитра = 60% цветов фото + 40% сдвиг по настроению
**Визуал:** скриншот блока «Рецепт дня».
**Сказать:** «Одинаковый ввод всегда даёт одинаковый результат. Это не случайный фильтр».

### 8. Как устроено
**Заголовок:** Анализ текста, фото и музыки идёт параллельно
**Схема:** текст → Gemini (настроение, детали, название) · фото → Pillow (цвета, свет) · песня → Deezer + librosa (BPM, биты, части, лад) → style_engine → плеер на canvas + WebAudio
**Таблица «часть — технология»:** API — FastAPI на Render · База и файлы — Supabase · Фронт — React, Canvas 2D, WebAudio, MediaRecorder на Vercel · Озвучка — edge-tts
**Сказать:** «Картинки нейросетью не генерируем: всё рисуется из фото пользователя нашими техниками».
