# Сценарий видео (до 3:00)

Правила хакатона: в видео только то, что реально работает. Запись экрана прототипа, голос за кадром свой. Без ИИ-видео.

**Что нужно до записи:** сайт на Vercel, 5–7 реальных дней команды в архиве (тестовые удалены), открыть сайт за 2 минуты до записи, чтобы сервер проснулся.

## Как снимать

- **Компьютер:** OBS Studio (бесплатно) → Sources → Display Capture + Audio Output Capture, чтобы писался звук песни. Разрешение 1920×1080, 30 fps.
- **Телефон:** встроенная запись экрана со звуком. Плеер 9:16 на телефоне смотрится лучше всего, сцену 0:55–1:30 лучше снять именно с телефона.
- Каждую сцену писать отдельным файлом по 2–3 дубля.
- Голос записать отдельно на телефон в тихой комнате, читать медленно.

## Монтаж (CapCut)

1. Положить клипы по порядку таблицы, обрезать ожидание.
2. Голос отдельной дорожкой. Музыку воспоминания не глушить там, где плеер играет (0:55–1:30): там голос тише или вообще пауза.
3. Субтитры: Текст → Автосубтитры (русский), проверить ошибки.
4. Экспорт 1080p, итог строго до 3:00.
5. Загрузить на Google Drive (доступ «все, у кого есть ссылка») или YouTube «по ссылке».
